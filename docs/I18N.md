# VisionQuery i18n rules (English + Arabic, RTL)

## API
```tsx
import { useT } from '../i18n';
const t = useT();                    // inside the component body (hooks rules apply)
t('Search')                          // the EXACT English text is the key
t('Every {n} frames', { n: value })  // placeholders in {braces}; numbers stay as numbers
```
Helper components or functions outside a component cannot call hooks: pass `t` to them as a parameter
(type: `(text: string, vars?: Record<string, string | number>) => string`).

## What to wrap
Every string a user can read: JSX text, `placeholder`, `title`, `aria-label`, button labels, empty states,
tooltips, template strings (turn `` `${n} matches` `` into `t('{n} matches', { n })`).
Plurals: separate keys, e.g. `n === 1 ? t('1 object') : t('{n} objects', { n })`.

## What NOT to wrap
CSS classes, URLs, ids, data from the server or the user (filenames, queries, detection labels like
"red car", colour hex codes), units inside numbers formatted by helpers (formatTime, formatPercent),
brand names (VisionQuery, YOLO-World, CLIP, SAM 2, FP16, FP32), keyboard keys ("Ctrl K", "Esc", "Enter").

## Right-to-left layout
In Arabic the page is `dir="rtl"`. Use Tailwind logical classes instead of physical ones for layout:
`ml-`→`ms-`, `mr-`→`me-`, `pl-`→`ps-`, `pr-`→`pe-`, `left-`→`start-`, `right-`→`end-` (positioned elements),
`text-left`→`text-start`, `text-right`→`text-end`, `rounded-l`→`rounded-s`, `rounded-r`→`rounded-e`,
`border-l`→`border-s`, `border-r`→`border-e`. Arrow/chevron icons that mean "next/forward" get `rtl:-scale-x-100`.

**Exception — keep left-to-right:** anything that maps to video pixels or time: canvas overlays, boxes placed
with percentage `left/top` from detection coordinates, the seek bar, the timeline track and its ruler, the
before/after slider, crops computed from boxes. Put `dir="ltr"` on those containers and keep their physical
classes and inline `left:` styles unchanged. Numbers, timestamps and file names may also use `dir="ltr"`.

## Do not change anything else
No logic, props, state, imports (except adding `useT`), or styling beyond the class swaps above.
Return the complete file.
